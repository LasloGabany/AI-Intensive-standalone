✓ Как это работает для клиента
  1. Скопировать Google Sheets шаблон → заполнить своими данными
  2. File → Share → Publish to web → выбрать вкладку → CSV → скопировать URL
  3. Открыть index.html → Setup экран → вставить URL → готово
  4. Данные обновляются автоматически при каждом открытии дашборда
