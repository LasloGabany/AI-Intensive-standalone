# Club Dashboard Template — Design Spec
_Дата: 2026-04-18_

## Цель

**Бесплатный** HTML-шаблон дашборда, который выдаётся подписчикам клуба как инструмент управления сообществом. Монетизация — не в шаблоне, а в данных: отчёты лучших практик, AI-анализы и обновления контента доступны только действующим подписчикам клуба. Шаблон = крючок удержания, данные = причина оставаться.

Клиент получает один `index.html`, открывает в браузере, редактирует данные в чётко размеченной DATA ZONE. Без бэкенда, без сборки, без зависимостей кроме CDN.

---

## Стек

| Компонент | Решение |
|-----------|---------|
| Рендеринг | Vanilla HTML/CSS/JS — единый `index.html` |
| Графики | Chart.js 4.4.1 (CDN) |
| Шрифт | Inter (Google Fonts CDN) |
| Данные | JS-константы в DATA ZONE в начале файла |
| Деплой | Открыть файл в браузере / положить на хостинг |

| `--yellow` | `#ffd166` | Предупреждение / метрики |

### Цветовая семантика (применяется везде)
- **Розовый/красный** → деньги (MRR), проблемы, что убрать
- **Зелёный** → ценность, рост, рекомендации, что добавить
- **Жёлтый** → конверсия, предупреждения, средний импакт
- **Серый** → технические детали, вторичная информация

## Разделы дашборда

### 1. Обзор (`#overview`)

**Источник данных:** `KPI`, `RETENTION`, `CHAT`

#### 1.1 KPI-карточки (4 штуки, grid 4-col)

| Карточка | Значение | Цвет значения |
|----------|----------|---------------|
| Активных подписок | число | белый |
| MRR (текущий месяц) | сумма + валюта | розовый `--pink` |
| CR Заказ→Оплата | % | жёлтый `--yellow` |
| Активность чата | число | жёлтый `--yellow` |

Каждая карточка: label (uppercase, серый) + badge (PBI/TG) + значение + subtitle + мини-спарклайн (SVG).

#### 1.2 Алерт-баннер критического периода

Условно отображается если `RETENTION.alertActive === true`.
Красный градиентный фон, 3 числа (истекают / продлили / осталось), прогресс-бар, дней осталось.

#### 1.3 Когортный ретеншн (левая колонка)

Таблица: когорты по строкам, M+0...M+N по столбцам.
Цветовая тепловая карта: ≥80% зелёный → 50-79% жёлтый → 30-49% оранжевый → <30% красный.
Звёздочки ★ для аномальных скачков (3-месячные подписки).
Подпись снизу для объяснения аномалий.

#### 1.4 Пульс чата (правая колонка)

- Area chart (Chart.js, `type: 'line'`, `fill: true`) с розовым градиентом
- 4 стат-блока: активных 7 дн / активных 30 дн / никогда не писали / платят молчат
- "Платят молчат" — с кликабельной стрелкой → переход в раздел Молчуны

#### 1.5 Тренд активности (полная ширина)

Chart.js line chart с:
- Ось X: даты (дд-мм формат), maxTicksLimit: 14
- Ось Y: мин. 0, подписи значений
- Легенда: "Среднее (7 дн)" справа сверху
- Area-заливка под линией, розовый градиент

### 3. Механики клуба (`#mechanics`)

**Источник данных:** `MECHANICS` (генерируется LLM из рыночного анализа)

#### 3.0 Поток генерации данных через внешний отчёт

// Вставка результата — парсит JSON, сохраняет в localStorage
// При следующем открытии: localStorage.MECHANICS перезаписывает
// константу MECHANICS из DATA ZONE
function applyMechanicsJSON(jsonStr) {

**Файлы отчётов (дистрибуция продавцом):**
- Формат: `.txt` или `.md` (читается любым редактором)
- Содержимое: структурированный текст с лучшими практиками, трендами, кейсами
- Обновление: раз в квартал → новый файл клиентам
- Размер: ~5–15 КБ (умещается в контекст LLM без обрезки)

### 4. Удержание и реактивация (`#retention`)

**Источник данных:** `RETENTION_DATA` (из экспорта Telegram-чата)

**Схема данных:**
```js
const RETENTION_DATA = {
  riskGroup: [
    {
      name: 'Любовь Скрипаченко',   // имя или TG ID если имя не задано
      username: 'LUBAVAS24',         // null если нет username
      messageCount: 232,             // всего сообщений
      activeDays: 82,                // дней была активна
      silentDays: 70,                // дней молчит
      priority: 'highest',           // 'highest' | 'high' | 'medium'
    }
  ],
  funnel: {
    silent14_30: 45,     // молчат 14-30 дн
    silent30_60: 38,     // молчат 30-60 дн
    silent60plus: 87,    // молчат 60+ дн
    neverWrote: 120,     // никогда не писали ("мёртвые души")
  }
};
```

**Логика приоритета** (вычисляется автоматически в JS):
- `highest` — silentDays > 60 ИЛИ messageCount > 100 (высокая потеря)
- `high`    — silentDays 30–60 ИЛИ messageCount 50–100
- `medium`  — silentDays 14–30 И messageCount < 50

#### 4.1 KPI-карточки (4 штуки, grid 4-col)

| Карточка | Значение | Цвет |
|----------|----------|------|
| Группа риска | кол-во из riskGroup | красный |
| Суммарно потеряно сообщ. | сумма messageCount по riskGroup | жёлтый |
| Ср. активность до ухода | среднее activeDays по riskGroup | белый |
| Никогда не писали | funnel.neverWrote | розовый |

#### 4.2 Таблица группы риска

**Subtitle:** "Участницы с 5+ сообщениями, молчащие более 14 дней."

Колонки: `#` | `ИМЯ` | `USERNAME` | `БЫЛО СООБЩЕНИЙ` | `БЫЛА АКТИВНА (ДНЕЙ)` | `МОЛЧИТ (ДНЕЙ)` | `ПРИОРИТЕТ`

- `USERNAME` — если не null: кликабельная ссылка `https://t.me/{username}` цвет `--orange`, открывает в новой вкладке. Если null — "—" серым.
- `ПРИОРИТЕТ` — бейдж: `highest` → красный "Высший", `high` → оранжевый "Высокий", `medium` → жёлтый "Средний"
- Сортировка по умолчанию: silentDays DESC (самые давно молчащие вверху)
- **Пагинация:** 25 строк на страницу, JS-клиентская. Кнопки: ← 1 2 3 … N →. Активная страница — розовый фон.

#### 4.3 Воронка потерь

Chart.js горизонтальный bar chart (`type: 'bar'`, `indexAxis: 'y'`):
- Категории (ось Y): "Молчат 14-30 дн" / "Молчат 30-60 дн" / "Молчат 60+ дн" / "Никогда не писали"
- Значения из `funnel.*`
- Цвет баров: градиент от оранжевого → красного по мере серьёзности
- Ось X: от 0 до max+10%

### 5. Отток: покинувшие клуб (`#churn`)

### 6. Молчуны (`#silent`)

**Назначение:** Модераторский триаж — фактическая инструкция кому писать в первую очередь. Приоритет: `статус подписки × уровень тишины × прошлая активность`. Не аналитика — операционный инструмент.

**Источник данных:** `SILENT_DATA` (из TG-экспорта + платёжных данных)

**Схема данных:**
```js
const SILENT_DATA = [
  {
    name: 'Анна Иванова',
    username: 'anna_iv',          // null если нет
    subscriptionActive: true,     // платит сейчас?
    subscriptionUntil: '2026-05-12',  // дата истечения ("ДО")
    postCount: 0,                 // всего сообщений ("ПОСТОВ")
    lastMessage: null,            // дата последнего сообщения ("ПОСЛЕДНЕЕ"), null = никогда
    silentDays: 87,               // дней молчит ("МОЛЧИТ")
    risk: 'red',                  // 'red' | 'yellow' | 'ghost' | 'expired'
    miniApp: true,                // использует мини-приложение ("МИНИАП")
  }
];
```

**Логика сегментации (вычисляется в JS):**
```
risk = 'ghost'   → subscriptionActive && postCount === 0
risk = 'red'     → subscriptionActive && silentDays >= 30 && postCount > 0
risk = 'yellow'  → subscriptionActive && silentDays >= 14 && silentDays < 30
risk = 'expired' → !subscriptionActive
```

#### 6.1 Фильтр-кнопки (pill-группа)

| Кнопка | Фильтр |

| 🔥 По приоритету | все, сортировка: ghost → red → yellow → expired |
| 🔴 Платит + молчит 30+ | subscriptionActive && silentDays ≥ 30 && postCount > 0 |
| 👻 Платит + никогда не писала | subscriptionActive && postCount === 0 |
| 🟡 Платит + 14–30д | subscriptionActive && silentDays ≥ 14 && silentDays < 30 |
| 💳 Все платящие молчуны | subscriptionActive && (silentDays ≥ 14 || postCount === 0) |

| Все | без фильтра |

### 10. Финансы (`#finances`)

**Источник данных:** `FINANCES_DATA` (GetCourse API / ручной экспорт)

#### 10.1 График «Выручка по месяцам»

**Chart.js `type: 'bar'`**, бейдж `GetCourse`.

- Ось X: Сен 25 → Апр 26

- Цвет столбцов: `--pink` (акцент)
